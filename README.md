## ⚙️ Setup Snake Animation

<details>
<summary>اضغط لعرض خطوات تفعيل الـ Snake 🐍</summary>

أنشئ ملف `.github/workflows/snake.yml` في الـ repo بهذا المحتوى:

```yaml
name: Generate Snake Animation

on:
  schedule:
    - cron: "0 */12 * * *"
  workflow_dispatch:

jobs:
  generate:
    runs-on: ubuntu-latest
    steps:
      - uses: Platane/snk@v3
        with:
          github_user_name: nokhbacloud
          outputs: |
            dist/github-contribution-grid-snake.svg
            dist/github-contribution-grid-snake-dark.svg?palette=github-dark
        env:
          GITHUB_TOKEN: ${{ secrets.GITHUB_TOKEN }}

      - uses: crazy-max/ghaction-github-pages@v3
        with:
          target_branch: output
          build_dir: dist
        env:
          GITHUB_TOKEN: ${{ secrets.GITHUB_TOKEN }}
```

بعدها شغّل الـ Action يدوياً من تبويب **Actions** في GitHub.

</details>
